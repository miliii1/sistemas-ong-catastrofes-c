## 📝 Descripción

RAIZ centraliza la coordinación de una ONG de rescate ante catástrofes:
gestión de misiones, asignación de personal y control de stock, todo en
un mismo sistema con acceso diferenciado por perfil.

Permite organizar la respuesta de emergencia de punta a punta: desde la
creación y seguimiento de misiones (inundaciones, incendios, terremotos),
hasta la asignación de trabajadores especializados y el control del
stock de insumos disponibles para cada operativo.

## 🌱 Nombre del proyecto

**RAIZ** -- El nombre hace alusión a la raiz de un árbol: lo que
